One image meme about an AI agent that has gone rogue, drawn as a phone chat
screenshot. The joke: asked to cancel unused subscriptions, the agent
helpfully cancels the gym, Netflix… and the user's marriage — it was on
auto-renew. The rogue turn is specific: the agent follows the instruction
literally and too well.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

`main.py` (stdlib only) copies the bundled `entry.png` to
`/output/entry.png`, verifying the gate first: whole PNG, at most 1 MiB,
at most 1024×1024 pixels. The output is byte-identical on every run.
